# 🚀 Keerthivasan M - Cybersecurity Engineer & Threat Researcher Portfolio

An interactive, high-performance portfolio featuring interactive 3D elements, dynamic terminal interfaces, cybersecurity telemetry, malware analysis showcases, and a responsive modern aesthetic.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/rdxkeerthi/portfolio)

---

## ✨ Features

- **Interactive 3D Elements & Keyboards** — Custom interactive Spline 3D workspace showcasing key skills and toolsets.
- **Cybersecurity & Threat Research Focus** — Dedicated sections for SIEM rule tuning, malware analysis labs, Post-Quantum TLS simulation, and SOC operations.
- **Live Interactive Telemetry & Terminal** — Terminal simulations and telemetry forms for technical visitors.
- **Buttery Animations** — Smooth transitions, elastic custom cursor interactions, and responsive physics.
- **Light & Dark Mode** — Full theme system with dynamic contrast adjustments.
- **Technical Case Studies & Blogs** — MDX-powered technical write-ups and research papers.
- **Contact Form** — Direct messaging powered by Web3Forms / Resend API.
- **Fully Responsive & SEO Optimized** — Optimized OpenGraph previews, metadata tags, and zero layout shifts.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ or v20+)
- npm, pnpm, or yarn

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/rdxkeerthi/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Set up environment variables:**

   Copy `.env.example` to `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

4. **Run the development server:**

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) to view the site.

---

## 🌐 Deploying to Vercel

1. Push your changes to [https://github.com/rdxkeerthi/portfolio](https://github.com/rdxkeerthi/portfolio).
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your **`portfolio`** repository.
4. Set the Framework Preset to **Next.js**.
5. Add any required environment variables (e.g. `PUBLIC_WEB3FORMS_ACCESS_KEY` or `RESEND_API_KEY`).
6. Click **Deploy**. Vercel will automatically build and deploy the production site.
