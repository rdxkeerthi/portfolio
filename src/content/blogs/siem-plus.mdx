# SIEM-Plus: Next-Generation Security Information & Event Management Platform

Enterprise Security Information and Event Management (SIEM) solutions often suffer from high licensing costs, sluggish batch query speeds, heavy resource-hogging agents, and complex proprietary rule languages. As attack vectors accelerate, security teams need real-time event correlation, native endpoint telemetry, and automated incident response out of the box.

**SIEM-Plus** is an open-source, next-generation SIEM platform designed from the ground up for high throughput, sub-second threat detection, and seamless Security Orchestration, Automation, and Response (SOAR) workflows.

## Architectural Deep Dive

### 1. Lightweight Rust EDR Endpoint Agent (`agent/`)
Built in Rust for minimal resource consumption (under 15MB RAM, less than 1% CPU load):
- **Process & Thread Monitoring**: Intercepts process creation (`execve` / `CreateProcessW`), parent-child process lineages, and command-line arguments.
- **File Integrity Monitoring (FIM)**: Employs `inotify` (Linux) and `ReadDirectoryChangesW` (Windows) to catch unauthorized system binary modifications or ransomware encryption behavior.
- **Live Interrogation Engine**: Allows SOC analysts to remotely run volatile memory queries, list open sockets, or isolate compromised hosts from the network.

### 2. Sigma-First Stream Detection Engine (`detect/`)
- **Native Sigma Integration**: Accepts standardized Sigma detection rule definitions without requiring manual conversion to SQL or proprietary search syntaxes.
- **In-Memory Stream Correlation**: Evaluates telemetry streams in real time against compiled Sigma rule predicates, triggering alerts within milliseconds instead of waiting for database indexing routines.
- **Stateful Sequence Matching**: Tracks multi-stage attack patterns (e.g., *Phishing attachment opened* $\rightarrow$ *PowerShell spawned* $\rightarrow$ *LSASS memory dumped* within 120 seconds).

### 3. OpenSearch Indexing & Storage Engine (`indexer/`)
- Handles index lifecycle management (ILM), automatic shard rollover, hot-warm-cold storage tiering, and data compression.
- Provides high-efficiency searching for retrospective threat hunting over billions of security events.

### 4. SOAR Playbook Automation (`soar/`)
- Executes automated response playbooks upon high-confidence alert triggers:
  - Automatically block malicious IPs at firewall edges (Palo Alto, Fortinet, AWS Security Groups).
  - Revoke compromised user sessions in Active Directory / Okta.
  - Isolate endpoints using the Rust agent daemon.
  - Dispatch alert notifications to Slack, Microsoft Teams, or PagerDuty.

### 5. Control Plane & Modern UI (`manager/` & `ui/`)
- **Frontend**: React-based dashboard featuring real-time event streaming graphs, node heatmaps, and rule management interfaces.
- **Backend API**: High-performance GraphQL and REST management API implemented in Go and TypeScript.

    pub timestamp: u64,

pub struct EndpointMonitor;
